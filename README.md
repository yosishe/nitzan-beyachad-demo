# בואו נכיר · ניצן ביחד

מוקאפ מתפקד בעברית וב־RTL, עם **גלילה אנכית בפרופיל וחיצים למעבר בין דיירים**.

הענף: `profile-to-profile-arrows`.

## איך מתנסים

- גוללים למטה כדי לראות תמונות וטקסט נוספים של אותו דייר.
- החץ השמאלי עובר לדייר הבא; החץ הימני חוזר לדייר הקודם.
- התמונות ניתנות להגדלה. לחיצה על התמונה המוגדלת או על ״חזור״ סוגרת אותה.
- נשמרו מסכי הדייר, העו״ס והאדמין, בקשות היכרות, שיחות, עזרה, דיווח, חסימה והסכמה להחלפת מספרים.
- אפשר לעבור בין תצוגות הדייר והצוות בתוך ההדגמה. כל הנתונים הם נתוני הדגמה.

[התנסות ציבורית בתצוגת טלפון](https://nitzan-beyachad-demo.cozy-eft-8123.chatgpt.site/compare.html?view=phone#scroll)

## הפעלה מקומית

אין צורך בבנייה או בהתקנת חבילות להפעלת האפליקציה. נדרש Python 3 להפעלת שרת קבצים מקומי:

```sh
git clone --branch profile-to-profile-arrows https://github.com/yosishe/nitzan-beyachad-demo.git
cd nitzan-beyachad-demo
python3 -m http.server 8000 --bind 127.0.0.1
```

פותחים בדפדפן: <http://127.0.0.1:8000/>.

קישורים מקומיים נוספים:

- דייר: <http://127.0.0.1:8000/#resident-demo>
- פרופילים: <http://127.0.0.1:8000/#profiles>
- עו״ס: <http://127.0.0.1:8000/#worker-mobile>
- אדמין: <http://127.0.0.1:8000/#admin-mobile>

## מוקאפ בלבד — ללא בקאנד

המצב נשמר בזיכרון הדפדפן בלבד ומתאפס ברענון. אין בסיס נתונים, הזדהות אמיתית, קריאות AI, משלוח SMS או דיווחים אמיתיים. החלפת התפקידים מדמה את אותה התרחשות באותו חלון; ההדגמה אינה מסנכרנת משתמשים או מכשירים שונים.

הפרדת התפקידים כאן היא הדגמת ממשק, ואינה מנגנון אבטחה למוצר אמיתי. אין להכניס מידע אישי אמיתי.

## קבצים

- `index.html` — האפליקציה המלאה בגרסת המעבר בין דיירים. העיצוב והלוגיקה משולבים בקובץ.
- `resident-photos-v1/` ו־`resident-photos-v1.js` — תמונות דמויות ההדגמה והמיפוי שלהן.
- `pictures-0b4a83f6c1.js` — נכסי תמונה נוספים של המוקאפ.
- `audioClips-fc76460235.js` — קובצי שמע מוטמעים להקראה; זהו נכס גדול במכוון.
- `phone-photo.js` ו־`phone-photo.css` — הגדלת תמונה בתוך תחומי מסך הטלפון המדומה.
- `SOURCE.json` — מזהה גרסת המקור וטביעות SHA-256 של קובצי האפליקציה.
- `tests/check_demo.py` — בדיקת ניווט, גלילה, הגדלה, טיוטת שיחה ותצוגות צוות.

כל נכסי האפליקציה הנדרשים כלולים במאגר. אין צורך בחשבון ChatGPT כדי להפעיל אותה.

## בדיקה

בחלון מסוף נוסף, בזמן שהשרת המקומי פועל:

```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r tests/requirements.txt
python3 -m playwright install chromium
python3 tests/check_demo.py
```

הבדיקה מפעילה את האפליקציה בדפדפן מקומי. אין צורך במפתחות או בשירות חיצוני.
